This book develops the quantitative tools used to analyse alternative investments: private equity and
private credit, real estate and other real assets, hedge funds, structured products and the derivatives that sit
underneath many of them. Each chapter pairs a concept with its mathematics, a worked example that can be checked
by hand, and Python code that reproduces every number and every figure. The code lives in the
\texttt{code/} folder of the repository, one subfolder per chapter. Unit tests, and independent checks in R and GNU
Octave, accompany the scripts, and every simulation states its seed.

The text, examples, figures and exercises are original.

Open source projects that shaped the writing style, the figures or the code are credited at the end of each
chapter and in the \texttt{CREDITS.md} file of the repository.
